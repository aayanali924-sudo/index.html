Universal Editor - Package
--------------------------
Files included:
- universal-editor.html    : single-file web app (open in Chrome/Edge).
- README.txt               : this file with quick start instructions.

Quick start:
1) Unzip the package and open 'universal-editor.html' in Chrome or Edge.
2) Make sure you have internet enabled (libraries load from CDN).
3) Upload an image (PNG/JPG) or a PDF.
   - For images: Auto detect & mask text → Inpaint → Download image.
   - For PDF: Render pages → select page → edit → Apply edits → Export edited PDF.
4) If OpenCV shows "not loaded", wait a few seconds and retry Inpaint.

Notes:
- All processing happens locally in your browser; files are not uploaded to any server.
- Do not use this tool for illegal activities (forgery, fraud, privacy invasion).
- If you want a zipped version with local copies of the JS libs (for offline use), ask me and I'll prepare it.
