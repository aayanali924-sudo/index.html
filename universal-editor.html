Universal Editor — Image + PDF editor (OCR, remove text, export)

OCR boxes will appear here when detection completes.
Tip: Use brush to refine mask. Use auto-detect to create mask from detected text boxes.
How it works: uploaded PDF pages are rasterized to canvas. Edit page, then "Apply" to store changes. Export builds a new PDF from edited page images.
Libraries used: Tesseract.js (OCR), OpenCV.js (inpainting), PDF.js (render), pdf-lib (create PDF). All run in your browser. No files uploaded to any server.
